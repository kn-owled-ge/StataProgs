# Data preparation for KnowledgeDynamics

Historical Stata code for preparing the data used by the [KnowledgeDynamics](https://github.com/kn-owled-ge/KnowledgeDynamics) structural-model research project.

## Orientation

- `Main.do` sets working paths, runs data preparation and assembles variables for the MATLAB workflow.
- `DataPrep.do` contains data preparation routines.
- `FromMatlab.do` supports the return path from MATLAB.
- The `.ado` files provide supporting commands.

This is a 2016 research snapshot with local Windows paths and external-data dependencies. Adapt paths and establish the required inputs before use. The repository does not provide external-data access rights, and this documentation update does not certify a complete replication environment.
